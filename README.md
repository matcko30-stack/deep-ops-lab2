# Лабораторна робота №2 — динамічний сайт-магазин DEEP OPS (CSS3, без JavaScript)

**Студент:** Мацько Богдан Володимирович, група 3-2з (ДТЕУ, спеціальність 122 «Комп'ютерні науки»).

6 основних сторінок і 70 сторінок товарів. Уся динаміка (меню, акордеони, фільтри моделей ПНБ, галереї, вкладки, вибір розміру) зроблена на чистому CSS3, без жодного рядка JavaScript.

Після публікації через **GitHub Pages** сайт відкривається за адресою `https://matcko30-stack.github.io/deep-ops-lab2/`.

## Як відкрити
- Онлайн: GitHub Pages (див. адресу вище).
- Локально: завантажте репозиторій (Code → Download ZIP), розпакуйте й відкрийте `index.html` у браузері.

## Структура
- `index.html`, `catalog.html`, `lookbook.html`, `compare.html`, `blog.html`, `contacts.html` — основні сторінки
- `product/` — 70 сторінок товарів
- `css/styles.css` — єдиний файл стилів; `fonts/` — Montserrat (OFL); `images/` — ілюстрації, фото фотожурналу, фото товарів (`images/products/`)
- `docs/` — опис роботи для звіту (`README_dlya_zvitu.md`), скріншоти, таблиця джерел фото (`docs/photos/photos_manifest.csv`)

> Фото товарів узято з сайтів магазинів і виробників як навчальна ілюстрація; джерела — у `docs/photos/photos_manifest.csv`. Фото фотожурналу використано з дозволу авторів.

Тема всіх лаб — DEEP OPS: спорядження для довготривалого дайвінгу та прилади нічного бачення. Навчальний проєкт; сайт не пов'язаний з підрозділами, згаданими на сторінках.
