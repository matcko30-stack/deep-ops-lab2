## 3. Тема і загальний опис
Тема — **інтернет-магазин DEEP OPS**: спорядження для довготривалого бойового дайвінгу та прилади нічного бачення (ПНВ). Методичка прямо дозволяє тему «Інтернет-магазин». Асортимент підібраний за мотивами екіпіровки морських підрозділів світу (73 МЦССО, US Navy SEALs, SBS, Shayetet 13, Commando Hubert) — це продовження інформаційного сайту з лаби 1, а далі той самий бренд використовується в лабах 10 і 11. Сайт не пов'язаний з підрозділами (є примітка у футері), символіка підрозділів не використовується, товари й ціни — приклад для навчального проєкту.

**Чому тема добре підходить під CSS3-динаміку:** картки товарів природно «оживають» при наведенні; порівняння типів ПНВ — це ідеальний випадок для анімованих прогрес-барів; тематика «нічного бачення» дала власні ефекти — зелений фільтр «режиму ПНВ» на фото і лінію сканування, як на екрані приладу. Темне оформлення «нічне море + зелений ПНВ» підкреслює тему.

**Головне обмеження:** жодного рядка JavaScript і жодних фреймворків — уся динаміка (меню, dropdown, акордеони, перемикач прогрес-барів, мобільне меню) зроблена на чистому CSS3 (псевдокласи `:hover`, `:focus-within`, `:checked`, «checkbox/radio hack»).

## 4. Перелік CSS3-ефектів (основна частина звіту)
Методичка вимагає мінімум 3 типи (анімація, перехід, трансформація) і мінімум 5 унікальних ефектів. Реалізовано **понад 25**:

### Інші вимоги методички
- **Натискна позначка на фото:**
```html
<div class="hotspot-wrap">
  <img src="images/photos/07_hoodie_net.jpg" alt="…" width="900" height="596" loading="lazy">
  <a href="product/hm-hoodie.html" class="hotspot" style="left: 57%; top: 60%;"><span>Худі</span></a>
</div>
```
```css
.hotspot { position: absolute; border-radius: 50%; animation: pulse 2s ease-in-out infinite; transition: transform 0.25s; }
.hotspot span { opacity: 0; transform: translate(-50%, 0.4rem); transition: opacity 0.25s, transform 0.25s; }
.hotspot:hover span, .hotspot:focus span { opacity: 1; transform: translate(-50%, 0); }
```

**Кнопка «Переглянути спорядження» без JS:**
```css
.look-panel { display: grid; grid-template-rows: 0fr; transition: grid-template-rows 0.45s ease; }
.look-check:checked ~ .look-panel { grid-template-rows: 1fr; }
@media (max-width: 768px) { .look-panel { grid-template-rows: 1fr; } .btn-look { display: none; } }
```

**@font-face:** власний шрифт Montserrat із папки `fonts/` (`font-display: swap`, діапазон `font-weight: 100 900`, бо шрифт змінний/variable). Шрифт зменшено до латиниці+кирилиці (з 745 КБ до 106 КБ). Ліцензія SIL Open Font License — дозволяє вільне використання (`fonts/OFL.txt`).
- **Градієнти:** `linear-gradient` у шапці, кнопках, прогрес-барах, тегах, заголовках.
- **rem/em:** усі розміри, відступи, радіуси в `rem`/`em`.
- **Media queries:** `max-width: 1024px` (2 колонки), `max-width: 768px` (`flex-direction: column`, бургер-меню), а також `prefers-reduced-motion: reduce` (вимикає анімації для людей, яким рух заважає).
- **will-change:** для логотипа, dropdown, slide-in, карток товарів, типів ПНВ, прогрес-барів, лінії сканування.
- **Префікси:** `-webkit-`, `-moz-` для `transition`, `transform`, `animation`, `@-webkit-keyframes`, `-webkit-clip-path`, `-webkit-filter`, `-webkit-background-clip`.
- **Коментарі** в CSS у форматі `/* Коментар: Анімація для шапки */` перед кожним ефектом.
- **JavaScript — 0 рядків. Фреймворків — немає.**

## 4г. Сторінки товарів (product/*.html)

Кожна картка в каталозі, кожна позиція в добірках фотожурналу, позначки на фото №7, картки «Типи приладів» на сторінці порівняння й кнопка «Хіт продажів» на головній ведуть на **власну сторінку товару на нашому сайті**, а не на сайт виробника. Сторінок 70, їх генерує скрипт за одним шаблоном (`lab2_products.py`, описи — `lab2_desc.py`).

**Що є на сторінці товару (усе без JavaScript):**
- «хлібні крихти»: Головна › Каталог › розділ › товар;
- **галерея на радіокнопках:** головна ілюстрація + фото реального приладу цього типу (для ПНВ магазину) або фото з фотожурналу, де видно схожу річ; мініатюри — це `<label>`, слайди змінюються з `opacity` і `transform`;
- назва, бренд, позначки, коротка анотація, **ціна в грн і €** з приміткою;
- **вибір кольору й розміру** — «чипи» на радіокнопках (`input:checked + label`);
- кнопка **«Замовити» / «Запитати ціну»** з пульсацією (`@keyframes`) веде на форму в контактах (`contacts.html#order`); кнопка **«В обране»** — checkbox hack, сердечко «підстрибує» (`@keyframes heart`);
- **вкладки «Опис / Характеристики / Доставка й гарантія»** на радіокнопках: опис у 2–3 абзаци, таблиця характеристик, умови доставки;
- для брендових моделей — «Бюджетна альтернатива від DEEP OPS», для власних речей — «Схожі моделі відомих брендів», для моделей ПНБ — «Не плутати з…» і зв'язок із товаром магазину того ж типу; для ПНВ магазину — блок «Реальні моделі цього типу»;
- «Схожа річ у фотожурналі» — мініатюри фото з переходом до потрібної серії;
- «Схожі товари» (4 картки з тієї ж групи) і перехід до попереднього / наступного товару.

**Клікабельна вся картка:** у HTML одне посилання в заголовку, а його `::after` розтягнуто на всю картку (`position: absolute; inset: 0`). Так немає дублікатів посилань для скрінрідера, а клікнути можна будь-де на картці.

```css
.card { position: relative; }
.card-link::after { content: ""; position: absolute; inset: 0; z-index: 2; }

/* Галерея: показується слайд з тим самим номером, що й обрана радіокнопка */
.p-gallery .g-input:nth-of-type(2):checked ~ .g-stage .g-slide:nth-child(2) {
  opacity: 1; visibility: visible; transform: none;
}

/* Вкладки */
.p-tabs .t-input:nth-of-type(2):checked ~ .t-panels .t-panel:nth-child(2) { display: block; }

/* Вибір розміру */
.opt-input:checked + label { border-color: var(--primary); color: var(--primary); }
```

Сторінки лежать у підпапці `product/`, тому генератор додає до локальних шляхів `../` (`../css/styles.css`, `../images/...`). Перевірено: 2008 локальних посилань на всіх сторінках — жодного битого.

## 7. Аналіз (окремий розділ звіту)
**Переваги CSS3 над JavaScript для таких ефектів:**
- анімації `transform` і `opacity` виконуються браузером на GPU (композитинг) — плавно, 60 fps, без навантаження на головний потік;
- менше коду і немає залежностей; ефекти працюють навіть із вимкненим JS;
- декларативність: стан описується (`:hover`, `:checked`), а не програмується;
- легко вимкнути весь рух одним `@media (prefers-reduced-motion: reduce)`.

**Проблеми / обмеження:**
- складна логіка без JS потребує «хаків» (checkbox/radio hack для акордеонів, перемикача й мобільного меню);
- немає подій типу «елемент з'явився при скролі» — анімації спрацьовують при завантаженні сторінки;
- **сумісність:** анімація `grid-template-rows` (акордеон) працює в Chrome/Edge 107+, Firefox 66+, Safari 16+; `clip-path` і `background-clip: text` у Chrome/Safari потребують префікса `-webkit-`; у старих браузерах ефекти просто не анімуються, але контент доступний;
- hover-ефекти не працюють на сенсорних екранах так само, як мишкою.

**Оптимізація:**
- анімуються переважно `transform`, `opacity`, `filter` (не викликають перерахунок макета);
- `will-change` для елементів, що анімуються;
- ілюстрації — SVG по 1–3 КБ; 13 фото стиснуто до 54–96 КБ кожне (усі < 100 КБ), `loading="lazy"` для фото нижче першого екрана;
- шрифт зменшено до потрібних символів (106 КБ замість 745 КБ), `font-display: swap`;
- `prefers-reduced-motion` для доступності.

**Тестування:** сторінки перевірено в Chromium на ширинах 1280px і 390px; усі локальні посилання, якорі (`catalog.html#products` тощо) та зображення працюють. Студенту: відкрити сайт у Firefox і Edge, переконатися, що все працює (за бажанням — скрін), і перевірити валідатором: HTML — https://validator.w3.org/#validate_by_upload, CSS — https://jigsaw.w3.org/css-validator/#validate_by_upload. **CSS-валідатор покаже попередження (warnings) на префікси `-webkit-`/`-moz-` — це нормально, вони додані навмисно за вимогою методички.** Якщо скрінів валідаторів немає — залиш позначки *[скріншот валідатора]*.

## 8. Висновки (тези)
- Освоїв ключові модулі CSS3: `@keyframes`/`animation`, `transition`, `transform` (translate, scale, rotate, skew), `filter`, `clip-path`, градієнти, `@font-face`, Grid і Flexbox, media queries.
- Зрозумів, що значну частину інтерактивності (меню, акордеони, перемикачі) можна зробити без JS — через `:hover`, `:focus-within`, `:checked` і селектори `~`, `+`.
- Навчився думати про продуктивність (які властивості дешево анімувати, `will-change`) і доступність (`prefers-reduced-motion`, `:focus-within` для клавіатури).
- **Труднощі:** анімація висоти до `auto` (вирішено через `grid-template-rows: 0fr → 1fr`); конфлікт анімації і transition на одній властивості в прогрес-барах (вирішено: при завантаженні анімується `transform: scaleX`, а при перемиканні — `width`); відступ під фіксовану шапку для якорів (`scroll-margin-top`); підбір комбінації фільтрів для «зеленого» ефекту ПНВ (`sepia` + `hue-rotate` + `saturate`); читабельність тексту в темній темі (контраст світлого тексту на темно-синьому фоні).
- Зробив 70 сторінок товарів за одним шаблоном: галерея, вкладки, вибір розміру й «обране» працюють на радіокнопках і чекбоксах, без JS.
- Зробив фільтрацію каталогу за двома ознаками без JS — радіокнопки, селектор `~` і `:not()`, а кількість результатів рахують CSS-лічильники.
- **Пропозиції:** додати кошик і пошук за назвою (потрібен JS), анімації при скролі (CSS `animation-timeline: view()`), світлу тему через `prefers-color-scheme`, справжню відправку форми; підключити оплату (зроблено в лабах 10–11 через WayForPay).
