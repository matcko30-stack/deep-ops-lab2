# Фото товарів — джерела й стан

`photos_manifest.csv`: для кожної з 62 карток — модель, посилання на джерело фото (`source_url`) і стан (`status`).

- **56** — фото на сайті (`images/products/`).
- **6** — фото не вдалося зберегти, у картці лишилася схема: ремінь, Dive Rite Wrist Slate (сайт не дає зберегти файл), гідрокостюм, кріплення камери, темно-синя футболка, Thales Bi-NYX (перевірка Cloudflare «я не робот»).
